# codex-healthkit v0.4.0

This normal source-only release adds an opt-in stable Codex CLI version check
that makes PATH precedence visible without changing or updating the installed
CLI.

## Highlights

- Add `--check-latest-codex` to compare the resolved Codex CLI with the official
  npm `latest` dist-tag for `@openai/codex`.
- Report the resolved executable path alongside the current and latest stable
  versions so duplicate installations can be distinguished.
- Keep the default check offline and preserve its JSON fields, summary status,
  exit code, and behavior.
- Treat network, response, and version parsing failures as metadata-only results.
- Never install, update, remove, or relink Codex automatically.

## Safety Boundary

- The version check is opt-in and performs one HTTPS GET to the public npm
  package metadata endpoint.
- No credential, token, cookie, SQLite content, or session transcript content
  is read.
- No telemetry, automatic history, daemon, cleanup, deletion, or update
  behavior is added.
- The result is informational and never changes the normal summary status or
  exit code.

## Install The Tagged Source

```bash
VERSION=v0.4.0
INSTALL_ROOT="$HOME/.local/opt/codex-healthkit"

mkdir -p "$INSTALL_ROOT"
git clone --branch "$VERSION" --depth 1 \
  https://github.com/Ishikawa-Hidekazu/codex-healthkit.git \
  "$INSTALL_ROOT/$VERSION"
ln -sfn "$INSTALL_ROOT/$VERSION" "$INSTALL_ROOT/current"
mkdir -p ~/.local/bin
ln -sfn "$INSTALL_ROOT/current/bin/codex-healthkit" \
  ~/.local/bin/codex-healthkit
```

Verify the selected source and run the opt-in version check:

```bash
codex-healthkit --version
codex-healthkit check --json | jq -e '.safety | all(.[]; . == false)'
codex-healthkit check --json --check-latest-codex
```

See the README for rollback guidance and the complete option reference.

## Distribution

This is a source-only release. GitHub-generated source archives are provided;
there are no manually attached binaries, package-manager releases, or automatic
updates.
