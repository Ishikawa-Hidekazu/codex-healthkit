# codex-healthkit v0.3.0

This normal source-only release adds opt-in session growth advisories and a
stable tag-pinned install path for daily use.

## Highlights

- Calculate a validated interval between explicit before-and-after reports.
- Report active session byte growth normalized to 24 hours.
- Evaluate optional `large_total` and `rapid_growth` advisory thresholds only
  when the user explicitly provides integer byte values.
- Keep default checks, summary status, and exit codes unchanged.
- Document versioned release directories, a stable `current` symlink,
  metadata-only verification, and symlink-only rollback.

## Safety Boundary

- No credential, token, or cookie reads.
- No SQLite content or session transcript content reads.
- No telemetry, automatic history, daemon, cleanup, deletion, or update
  behavior.
- The sessions advisory is informational and never changes the normal summary
  status or exit code.

## Install The Tagged Source

```bash
VERSION=v0.3.0
INSTALL_ROOT="$HOME/.local/opt/codex-healthkit"

mkdir -p "$INSTALL_ROOT"
git clone --branch "$VERSION" --depth 1 \
  https://github.com/Ishikawa-Hidekazu/codex-healthkit.git \
  "$INSTALL_ROOT/$VERSION"
ln -sfn "$INSTALL_ROOT/$VERSION" "$INSTALL_ROOT/current"
mkdir -p ~/.local/bin
ln -sfn "$INSTALL_ROOT/current/bin/codex-healthkit" \
  ~/.local/bin/codex-healthkit
```

Verify before daily use:

```bash
codex-healthkit --version
codex-healthkit check --json | jq -e '.safety | all(.[]; . == false)'
```

See the README for rollback guidance and the complete option reference.

## Distribution

This is a source-only release. GitHub-generated source archives are provided;
there are no manually attached binaries, package-manager releases, or automatic
updates.
